Linking Pages

Connect pages with wiki links. Type two square brackets and start typing a page name; the app suggests matching titles and aliases.

Four link forms

  • Install — a bare page name [[Install]]
  • Getting Started/Using Chat — a folder path [[Getting Started/Using Chat]]
  • Welcome › Next steps — a page and a heading [[Welcome#Next steps]]
  • the Alpha project — display text [[Overview|the Alpha project]]
